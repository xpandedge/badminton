# DuoRally User Guide

DuoRally helps badminton and pickleball groups run social doubles sessions without spreadsheets, manual rotations, or constant "who is on next?" messages.

Use this guide for two audiences:

- Organisers and admins who create squads, schedule sessions, run courts, enter scores, and manage changes during play.
- Members and players who join squads, RSVP, check court assignments, and follow scores or rankings.

## Core Terms

**Squad**
A reusable group of people who play together, such as a club night, work crew, or regular social session.

**Member**
A signed-in person who belongs to a squad. Members can see squad sessions, RSVP, and follow their own games.

**Guest player**
A player added by an organiser without requiring that person to create an account. Guests can be included in sessions and scoring.

**Session**
One play event with a sport, venue, courts, players, rounds, scores, and a leaderboard.

**Round**
A batch of matches played at the same time. If you have 3 courts, one round can contain 3 doubles matches.

**Re-pick**
DuoRally's action for regenerating court assignments when players arrive, leave, or the organiser wants a fairer current rotation. Completed games are preserved.

## Getting Started

1. Open DuoRally and sign in.
2. Choose your sport preference if prompted: badminton or pickleball.
3. Use the dashboard to start a session, open squads, view joined sessions, or check rankings.
4. Use the bottom navigation for quick access to Home, Session, Groups, and Help.

## Guide For Organisers And Admins

### Create A Squad

1. Go to **Groups**.
2. Select **Create Squad**.
3. Enter the squad name and optional description.
4. Submit the form.

The creator becomes the squad owner. Use the squad page as the home base for members, sessions, invite codes, venues, and player management.

### Invite Members

1. Open the squad.
2. Copy the invite code.
3. Share the code with players.
4. When players request to join, review the **Join Requests** list.
5. Approve or decline each request.

Members can also search for a squad by name and request access.

### Add Players Or Guests

Use guests for one-off players, fill-ins, or people who do not want to create an account.

1. Open the squad.
2. Go to the members or roster area.
3. Add a player name and skill level if known.
4. Use guest players when no sign-in is needed.

Skill levels help DuoRally balance teams. Use **unknown** if you are not sure.

### Add Venues And Courts

1. Open the squad.
2. Find the venue and courts area.
3. Add the venue name.
4. Add each court that can be used for sessions.
5. Mark the regular venue as the home venue if the option is available.

Courts can be included when a session is created or re-picked.

### Create A Session

1. Tap **Session** in the bottom navigation or **Start a session** on the dashboard.
2. Select the squad.
3. Enter a session name.
4. Choose badminton or pickleball.
5. Choose the venue and courts.
6. Set the session duration and estimated game length.
7. Choose the scoring mode:
   - **Winner only**: record which team won.
   - **Points**: record the exact score.
8. Set a date and time for a scheduled session, or leave it blank to start immediately.
9. Create the session.

### Let Members RSVP

Scheduled sessions appear in the squad's session list. Members can mark themselves as **Going** or **Not Going**.

Use RSVP counts to estimate numbers before the session starts. Members marked **Going** can be added to the player list automatically, depending on the current session flow.

### Start A Live Session

1. Open the session.
2. Open the **Live Console**.
3. Confirm that at least 4 active players are available.
4. Tap **Start Session**.

DuoRally generates doubles matches based on players, courts, duration, skill levels, and fairness.

### Run The Courts

During a live session, the Live Console shows:

- Current matches by court.
- Team A and Team B.
- Players sitting out or waiting.
- Score controls.
- Session controls.
- Leaderboard.
- Rotation health or fairness information where available.

Players can use their own session view or the shared board view to see where they are playing.

### Enter Scores

For winner-only scoring:

1. Find the match.
2. Tap **A Wins** or **B Wins**.

For points scoring:

1. Enter Team A and Team B scores.
2. Save the score.
3. DuoRally calculates the winner.

Completed matches update the leaderboard and are treated as locked so future re-picks do not erase them.

### Share A Scorekeeping Link

If a court volunteer is entering scores:

1. Open the session details.
2. Find the scorekeeping link section.
3. Share the link with the volunteer.

The scorekeeping link is intended for quick score entry without giving the volunteer full organiser controls.

### Add A Late Player

1. Open the Live Console or session details.
2. Add the player from the squad roster, or add a guest.
3. Re-pick the current or future matches.

The new player is included from the next available rotation. Completed matches remain unchanged.

### Mark A Player As Waiting, Left, Or Removed

Use player status controls when someone needs to stop playing or sit out.

- **Waiting**: the player is present but not currently on court.
- **Left**: the player has left and should not be scheduled into future matches.
- **Removed**: the player is removed from the session rotation.
- **Active**: the player is available again.

After changing status, re-pick to redistribute future court assignments.

### Re-Pick Matches

Use **Re-pick Current Matches** when:

- A player arrives late.
- A player leaves.
- A court becomes available or unavailable.
- The current rotation needs a fairness reset.
- The organiser has made manual changes and wants a clean schedule from here.

Re-picking preserves completed games and updates future assignments.

### Pause, Resume, Complete, Or Cancel

Use session controls from the Live Console:

- **Pause** when play is temporarily stopped.
- **Resume** when play continues.
- **Complete Session** when the session is finished.
- **Cancel / Delete Session** when the session should no longer be used.

Complete the session when all final scores are entered so rankings and history are clean.

### View Rankings

Use **Rankings** from the dashboard to see all-time player stats. Rankings are based on completed match results and may include played games, wins, losses, win percentage, points, and point differential depending on the current app view.

## Guide For Members And Players

### Join A Squad

With an invite code:

1. Go to **Groups**.
2. Enter the invite code in **Join a squad**.
3. Submit the request or join directly if allowed.

By search:

1. Go to **Groups**.
2. Search for the squad name.
3. Tap **Request**.
4. Wait for the organiser to approve you.

Once approved, the squad appears on your dashboard and Groups page.

### RSVP To A Session

1. Open your squad.
2. Go to the sessions area.
3. Find the upcoming session.
4. Choose **Going** or **Not Going**.

You can usually change your RSVP before the session starts.

### Find Your Session

From the dashboard:

- **My Sessions** shows sessions you organise.
- **Joined** shows sessions where you are a player.

From the squad page:

- Open the squad.
- Go to the sessions list.
- Select the session.

### Check Your Court Assignment

Open the session player view to see:

- Whether you are playing now.
- Which court you are on.
- Your partner.
- Your opponents.
- Whether you are waiting or sitting out.
- Your completed results.

Keep the page open during the session. Assignments can update when the organiser re-picks.

### Follow Scores And Leaderboard

The session view shows live scores and leaderboard updates as matches are completed.

If the organiser shares a board link, open it to see a simplified public-style view of the current courts and leaderboard.

### If You Arrive Late

Tell the organiser when you arrive. They can add you to the session and re-pick future matches so you are included in the next possible rotation.

### If You Need To Leave

Tell the organiser before your next match if possible. They can mark you as left and re-pick future matches without changing completed results.

### Check All-Time Rankings

Tap **Rankings** from the dashboard to see overall stats across completed sessions. Rankings generally prioritise wins first, then point difference.

## Guest Player Notes

Guests can be added by an organiser without signing in. This is useful for casual fill-ins.

Guest players:

- Can be scheduled into matches.
- Can have scores recorded.
- May appear in session results.
- May not appear in all-time signed-in user rankings, depending on the ranking view.
- Do not manage their own account unless they later sign up.

## Best Practices For A Smooth Session

- Add players and courts before the session starts.
- Use RSVP for scheduled sessions so player counts are known early.
- Set realistic estimated game time. Short estimates create more rounds.
- Use skill levels when known, but do not overthink them.
- Enter scores as soon as games finish.
- Re-pick after late arrivals, early departures, or court changes.
- Complete the session when play ends.

## Troubleshooting

**I cannot create a session.**
Make sure you are signed in and belong to a squad. You may need organiser or owner permissions.

**I cannot join a squad.**
Check the invite code, or search for the squad by name and request access. The organiser may need to approve you.

**A player is missing from a session.**
Check whether they RSVP'd **Going**, are in the squad roster, or were added as a guest. Add them manually if needed.

**The app will not generate matches.**
You need at least 4 active players for doubles. Also check that the session has at least one active court.

**A completed game changed after re-picking.**
Completed games should be preserved. If something looks wrong, stop entering new scores and ask the organiser to review the session before continuing.

**A player left but still appears in future games.**
Mark the player as **Left** or **Removed**, then re-pick.

**Scores look wrong.**
Ask an organiser to review the match. If score editing is enabled, they can correct it and the leaderboard should update.
