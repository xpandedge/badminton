# Help Current Features Design

## Goal

Keep the existing role-based Help experience while making every instruction match the current DuoRally product.

## Content Direction

The organiser guide follows the real flow: create and share a squad, create a session, use home-page RSVPs, add the roster with Add all or individual controls, add session-only guests, start play, protect current games, handle swaps and attendance changes, score games, and share the player or score-entry links.

The player guide covers Google signup, existing email/password sign-in and recovery, changing the player name from the header initials, joining from Home, responding Going or Not going from Home, following the highlighted live or next session, using the Player Board, and understanding session versus overall rankings.

Stale references to squad-level guest setup, Joined tabs, waiting controls, manual shuffle controls, and re-picking visible games are removed.

## UI Scope

No Help layout or navigation changes are required. The role switch, search, expandable sections, quick starts, and troubleshooting cards remain intact and mobile-friendly.
